Personal portfolio — **Desenvolvedor Fullstack Júnior**

Built with vanilla HTML, CSS, and JavaScript. Zero dependencies, zero build step, hosted on GitHub Pages.

## About

Desenvolvedor Fullstack Júnior, formado em Análise e Desenvolvimento de Sistemas pela Universidade Católica de Brasília (UCB). Experiência prática entregando produtos de ponta a ponta: aplicativo mobile publicado na Google Play com autenticação e pagamentos in-app, sistemas internos de gestão e automações com Next.js, React Native, Node.js, Fastify, TypeScript e PostgreSQL.

## Features & Tech Stack

- EN / PT language toggle
- Scroll-triggered reveal animations & dynamic intro
- Custom cursor & scroll progress bar
- Sections: Experiência · Projetos · Skills · Reconhecimentos & Prêmios · Formação · Sobre mim · Contato
- SEO meta tags + Schema.org Structured Data
- Fully responsive design

**Stack:** HTML5 · Vanilla CSS · JavaScript (ES6+) · Google Fonts · GitHub Pages
